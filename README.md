# Grade Calculator

A console program for teachers. The teacher types a student's name and 5 scores, and the program shows the average and the grade. Several students can be entered in one run; at the end the program shows how many students were entered and the class average.

## Requirements
- The program shall ask for a student's name and stop when the teacher types "end" instead of a name.
- The program shall read exactly 5 whole-number scores for each student.
- The program shall reject any score outside 0–100, show an error message and ask for the same score again.
- The program shall calculate each student's average and display it with 1 decimal place together with the grade A, B, C or F.
- The program shall display the number of students entered and the class average when the teacher types "end".

## Grading scale
| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | below 60 |

## How to run
1. Open https://www.onlinegdb.com and choose C++.
2. Paste the code from main.cpp and click Run.
